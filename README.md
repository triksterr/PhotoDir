# PhotoDir
Photo Directories - Sorter for You photos

Программа сортировки файлов фото и видео по папкам PhotoDir v2.01 от 08.05.2021

Программа написана группой (c) KTSoft в рамках проекта RUBasic.

Программа раскладывает файлы по папкам с именами, соответствующими датам - вида: ГГГГММДД

Программа работает с файлом настроек, который может находиться в папке программы или в обрабатываемой папке. Приоритет имеет файл, находящийся в обрабатываемой папке. В случае отсутствия файла настроек программа создает его в минимальном объёме - по умолчанию.

Для работы программе необходимо передать (в параметрах командной строки, например, путём перетаскивания мышью) путь к обрабатываемой папке.

## Установка

Для установки программы скопируйте папку с программой в удобное место, например, в папку C:\Program Files\

Для удобного взаимодействия с программой:

Создание ссылки в контекстном меню папок:
- Создайте ярлык к программе. Переименуйте его как вам удобно, например, просто "PhotoDir"
- В Меню пуск - Выполнить... - "shell:sendto". Откроется папка SendTo, содержащая несколько ярлыков.
- Переместите ярлык в эту папку.

Теперь при открытии контекстного меню папки правой кнопкой мыши выберите `Отправить - PhotoDir`. Программа запустится в выбранной папке.


Пример файла настроек "settings.txt":

extensions:  
jpg  
jpeg  
png  
mp4  
gif  
dateformats:  
yyyymmdd  
yyyy.mm.dd  
yyyy-mm-dd  
IMG_yyyymmdd  
IMG-yyyymmdd  
VID_yyyymmdd  
VID-yyyymmdd  
image-yyyymmdd  
Screenshot_yyyymmdd  
Screenshot yyyy-mm-dd  
yyyymmdd  
.

Пробелы и пустые строки в файле настроек - не допускаются!

Раздел `extensions` содержит список расширений файлов - по 1-му расширению в строке, без точек.
Расширения - только в нижнем регистре!

Раздел  `dateformats` содержит форматы дат (имена файлов) - по 1-му в строке.
Коды форматов дат - в нижнем регистре!
`yyyy` - год  
`mm` - месяц  
`dd` - день  

Остальные символы:  
`?` - один любой символ  
`*` - много любых символов  
Все остальные символы - точное соответствие символам в имени файла.
После символов по формату в имени файла может далее присутствовать любое количество любых символов - ставить `*` - не обязательно.

В конце списка настроек должна быть строка, содержащая одну точку в первой позиции. 

Файл настроек может находиться в папке программы и/или в обрабатываемой папке, но если файл присутствует в обрабатываемой папке, то именно он и будет использован.

### Примечание.

Очень эффективно работают шаблоны типа:

`??????????????????yyyymmdd???????`

для файлов с названием типа:

`Panasonic DC-FZ82_20231028_230124`

Такие шаблоны очень просто создавать и использовать.
